# 分类方案对比分析

## 🎯 5分类定义（当前TCT标准）

### 类别说明

| 类别ID | TCT代码 | 英文名称 | 中文名称 | 临床意义 |
|--------|---------|----------|----------|----------|
| 0 | NILM | Normal | 正常/阴性 | 无异常细胞 |
| 1 | ASC-US | Atypical Squamous Cells of Undetermined Significance | 非典型鳞状细胞-意义不明 | 轻微异常，需要随访 |
| 2 | LSIL | Low-grade Squamous Intraepithelial Lesion | 低度鳞状上皮内病变 | 轻度病变，可能自愈 |
| 3 | HSIL | High-grade Squamous Intraepithelial Lesion | 高度鳞状上皮内病变 | 高度病变，需要治疗 |
| 4 | ASC-H/SCC/Cancer | Atypical Squamous Cells/Carcinoma | 癌变/恶性 | 癌前病变或恶性肿瘤 |

### 当前数据分布

```
总样本: 785个

类别0 (NILM):        275样本 (35.0%)  ✅ 充足
类别1 (ASC-US):       14样本 (1.8%)   ⚠️ 极少
类别2 (LSIL):          4样本 (0.5%)   ❌ 严重不足
类别3 (HSIL):          4样本 (0.5%)   ❌ 严重不足
类别4 (Cancer):       488样本 (62.2%)  ✅ 充足

类别平衡度: 0.008 (严重不平衡)
```

**问题**: 类别2和3分别只有4个样本，**无法支撑正常的深度学习训练**

---

## 🎯 3分类方案（推荐）

### 合并策略

| 原5类别 | 合并后 | 新类别 | 样本数 | 百分比 |
|---------|--------|--------|--------|--------|
| NILM (类别0) | 正常 | 新类别0 | 275 | 35.0% ✅ |
| ASC-US (类别1) + LSIL (类别2) | 低度病变 | 新类别1 | 18 | 2.3% ⚠️ |
| HSIL (类别3) + Cancer (类别4) | 高度病变 | 新类别2 | 492 | 62.7% ✅ |

### 标签映射

```python
def map_to_3class(tct_5class):
    """5分类到3分类映射"""
    if tct_5class == 0:
        return 0  # 正常
    elif tct_5class in [1, 2]:
        return 1  # 低度病变（ASC-US + LSIL）
    elif tct_5class in [3, 4]:
        return 2  # 高度病变（HSIL + Cancer）
```

### 优点

✅ **数据分布更合理**
- 最小类别18个样本（vs 原来的4个）
- 平衡度提升到0.037

✅ **临床意义明确**
- 正常 vs 低度病变 vs 高度病变
- 符合临床分级习惯

✅ **训练可行**
- 虽然不是完美平衡，但可用few-shot learning处理

✅ **实用性高**
- 能够区分需要随访的（低度）和需要立即治疗的（高度）

### 预期性能

- **整体准确率**: 70-75%
- **正常类准确率**: >90%
- **高度病变准确率**: >80%
- **低度病变准确率**: 40-50%（样本少，使用few-shot）

## 🎯 4分类方案（次选）

### 合并策略

| 原5类别 | 合并后 | 新类别 | 样本数 | 百分比 |
|---------|--------|--------|--------|--------|
| NILM (类别0) | 正常 | 新类别0 | 275 | 35.0% ✅ |
| ASC-US (类别1) | 轻度异常 | 新类别1 | 14 | 1.8% ⚠️ |
| LSIL (类别2) + HSIL (类别3) | 中高度病变 | 新类别2 | 8 | 1.0% ❌ |
| Cancer (类别4) | 恶性病变 | 新类别3 | 488 | 62.2% ✅ |

### 标签映射

```python
def map_to_4class(tct_5class):
    """5分类到4分类映射"""
    if tct_5class == 0:
        return 0  # 正常
    elif tct_5class == 1:
        return 1  # 轻度异常（ASC-US）
    elif tct_5class in [2, 3]:
        return 2  # 中高度病变（LSIL + HSIL）
    elif tct_5class == 4:
        return 3  # 恶性病变（Cancer）
```

### 优缺点

⚠️ **问题**:
- 中高度病变仅8个样本
- 轻度异常仅14个样本
- 仍然存在严重的类别不平衡

✅ **优点**:
- 分级更细致
- 更接近原始TCT分类

## 🎯 最终推荐

### **优先使用3分类方案**

**理由**:
1. ✅ 数据分布最合理（最小类别18个样本）
2. ✅ 临床意义清晰（正常/低度病变/高度病变）
3. ✅ 训练可行性高
4. ✅ 预期性能可观（70-75%准确率）
5. ✅ 可用于few-shot learning处理低度病变类

**实施建议**:
1. 使用已创建的`5centers_multi_3class`数据集
2. 对低度病变类（18样本）使用强数据增强
3. 考虑few-shot learning或prototypical networks
4. 使用Focal Loss处理类别不平衡
