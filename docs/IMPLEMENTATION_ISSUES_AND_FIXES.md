# 实现问题与修复报告

## 🔴 发现的问题

### 1. JSON序列化错误
**问题**：`TypeError: Object of type float16 is not JSON serializable`
- **原因**：NumPy的float16类型不能直接序列化为JSON
- **影响**：训练在保存指标时崩溃

### 2. 可学习因果图的梯度传播问题
**问题**：在`forward`中平均batch维度，导致梯度无法正确传播
- **原因**：`learned_causal.mean(dim=0)` 丢失了batch维度
- **影响**：可学习因果图无法正确训练，性能差

### 3. DAG约束实现过于简单
**问题**：只使用了简单的上三角矩阵，没有真正的理论保证
- **原因**：缺少NOTEARS算法的DAG惩罚项
- **影响**：无法确保因果图真正无环

### 4. 因果图未在损失函数中使用
**问题**：学习到的因果图没有正则化损失
- **原因**：损失函数中没有包含因果图惩罚项
- **影响**：因果图可能学习到不合理的结构

### 5. 特征维度不匹配
**问题**：数据集返回512维特征，模型期望768维
- **原因**：特征提取器没有正确处理维度投影
- **影响**：特征无法正确输入模型

### 6. 学习率可能过高
**问题**：初始学习率1e-4可能导致训练不稳定
- **原因**：新模型需要更小的学习率
- **影响**：训练不稳定，性能差

---

## ✅ 修复方案

### 1. JSON序列化修复
```python
def convert_to_serializable(obj):
    """将numpy/torch类型转换为Python原生类型"""
    if isinstance(obj, np.ndarray):
        return obj.tolist()
    elif isinstance(obj, (np.float16, np.float32, np.float64)):
        return float(obj)
    # ... 其他类型转换
```

### 2. 可学习因果图梯度修复
- **修复前**：`learned_causal.mean(dim=0)` → `[num_modalities, num_modalities]`
- **修复后**：保持batch维度 → `[B, num_modalities, num_modalities]`
- **影响**：支持正确的梯度传播

### 3. DAG约束改进
- **添加**：`compute_dag_penalty()` 方法
- **实现**：基于NOTEARS的DAG惩罚项
- **公式**：`penalty = relu(expm_trace - num_modalities)^2`

### 4. 因果图正则化损失
- **添加**：在损失函数中加入因果图惩罚项
- **权重**：`causal_loss_weight = 0.01`
- **公式**：`total_loss = ce_loss + kl_loss + contrastive_loss + causal_penalty`

### 5. 特征维度投影修复
- **修复**：在`FeatureExtractor`中添加投影层
- **实现**：自动检测维度并投影到768维

### 6. 学习率调整
- **修复前**：`lr = 1e-4`
- **修复后**：`lr = 1e-4 * 0.5 = 5e-5`
- **影响**：提高训练稳定性
