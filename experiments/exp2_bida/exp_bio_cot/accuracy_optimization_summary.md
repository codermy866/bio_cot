# 准确率优化方案总结

## 问题分析

从训练日志发现第一个batch的准确率只有**40.62%**，低于随机猜测（50%），主要原因：

1. **对抗损失过高**：虽然权重只有0.05，但对抗损失值1.8372很高，在训练初期干扰分类任务
2. **Dropout过高**：分类器中有0.4和0.3的dropout，训练初期影响学习能力
3. **辅助损失权重过高**：OT损失、一致性损失、对抗损失在训练初期就全权重参与，干扰主任务学习

## 优化措施

### 1. 降低分类器Dropout（`bio_cot_model.py`）
- 第一层dropout：0.4 → **0.2**
- 第二层dropout：0.3 → **0.15**
- 提高训练初期的学习能力

### 2. 调整损失权重（`train_bio_cot_optimized.py`）
- 分类损失权重：2.0 → **3.0**（进一步提高主任务权重）
- OT损失权重：0.1 → **0.05**（减少干扰）
- 一致性损失权重：0.2 → **0.1**（减少干扰）
- 对抗损失权重：0.05 → **0.01**（大幅降低干扰）

### 3. 动态权重调整（`train_bio_cot_optimized.py`）
- 前5个epoch：辅助损失权重从30%逐渐增加到100%
- 公式：`epoch_factor = 0.3 + 0.7 * epoch / 5`（epoch < 5时）
- 让模型先专注于分类任务，再逐渐引入辅助约束

### 4. 增强调试信息
- 添加logits的均值和标准差
- 添加softmax概率分布信息
- 显示加权后的辅助损失值
- 显示epoch_factor调整因子

## 预期效果

1. **训练初期准确率提升**：降低dropout和辅助损失干扰，让模型更快学习分类任务
2. **更稳定的训练**：动态权重调整避免早期训练被辅助任务干扰
3. **更好的最终性能**：先学好主任务，再引入辅助约束，平衡性能和泛化

## 使用说明

重新运行训练脚本即可应用这些优化：
```bash
python experiments/exp2_bida/train_bio_cot_optimized.py
```

训练日志会显示更详细的调试信息，包括：
- logits的统计信息
- 加权后的损失值
