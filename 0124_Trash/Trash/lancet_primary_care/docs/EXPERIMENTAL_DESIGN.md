# The Lancet Primary Care - 实验设计方案

## 🎯 研究目标

通过多模态AI技术优化宫颈癌初筛流程，实现以下四个核心目标：

1. **降低HPV+患者的过度活检率**
2. **提高OCT的灵敏度**
3. **优于HPV+TCT或单独TCT**
4. **优化宫颈癌初筛流程**

---

## 📊 实验1: HPV+患者活检率降低实验

### 1.1 研究假设

**H0**: 多模态AI与传统HPV+TCT方案在活检率上无显著差异  
**H1**: 多模态AI可以显著降低HPV+患者的活检率，同时保持或提高灵敏度

### 1.2 实验设计

#### 队列定义
- **目标人群**: HPV+患者（HPV检测阳性）
- **样本量**: 从现有数据集中筛选HPV+患者
- **分组**:
  - **对照组**: 传统HPV+TCT方案（任一阳性即建议活检）
  - **实验组**: 多模态AI方案（基于风险分层决策）

#### 评估指标

**主要终点**:
- **活检率降低**: `(对照组活检率 - 实验组活检率) / 对照组活检率 × 100%`
- **目标**: 降低30-50%的活检率

**次要终点**:
- **灵敏度保持**: 实验组灵敏度 ≥ 对照组灵敏度（非劣效性）
- **PPV提升**: 实验组PPV > 对照组PPV
- **NPV保持**: 实验组NPV ≥ 对照组NPV

#### 风险分层策略

**三级风险分层**:
1. **高风险** (建议活检):
   - AI预测概率 > 0.7
   - 或 OCT+Colposcopy+Clinical 综合评分 > 阈值

2. **中风险** (建议随访):
   - AI预测概率 0.3-0.7
   - 或 单一模态异常

3. **低风险** (建议常规随访):
   - AI预测概率 < 0.3
   - 且 所有模态正常

#### 统计方法
- **配对t检验**: 比较活检率差异
- **McNemar检验**: 比较分类结果
- **非劣效性检验**: 验证灵敏度非劣效性（非劣效性界值: -5%）

## 📊 实验2: OCT灵敏度提升实验

### 2.1 研究假设

**H0**: AI增强的OCT分析灵敏度与人工判读无显著差异  
**H1**: AI增强的OCT分析灵敏度显著高于人工判读

### 2.2 实验设计

#### 队列定义
- **目标人群**: 所有有OCT数据的患者
- **金标准**: 组织病理学（活检结果）

#### 评估指标

**主要终点**:
- **OCT灵敏度**: `TP / (TP + FN)`
- **目标**: AI增强OCT灵敏度 > 85%（传统OCT约70-75%）

**次要终点**:
- **OCT特异度**: `TN / (TN + FP)`
- **OCT AUC**: ROC曲线下面积
- **早期病变检出率**: CIN1+检出率

#### 对比方案
1. **传统OCT判读**: 基于临床经验的视觉判读
2. **AI增强OCT**: 多模态AI模型中的OCT分支
3. **多模态AI**: OCT + Colposcopy + Clinical

#### 统计方法
- **ROC曲线分析**: 比较AUC
- **DeLong检验**: 比较ROC曲线差异
- **灵敏度提升**: `(AI灵敏度 - 传统灵敏度) / 传统灵敏度 × 100%`

## 📊 实验3: 筛查方案对比实验

### 3.1 研究假设

**H0**: 多模态AI与HPV+TCT或单独TCT在诊断性能上无显著差异  
**H1**: 多模态AI的诊断性能显著优于HPV+TCT和单独TCT

### 3.2 实验设计

#### 对比方案

**方案A: 单独TCT**
- 决策规则: TCT异常（ASC-US+）→ 建议活检

**方案B: HPV+TCT联合**
- 决策规则: HPV+ 或 TCT异常 → 建议活检

**方案C: 多模态AI（本研究）**
- 决策规则: 基于多模态AI风险评分 → 分层管理

#### 评估指标

**主要终点**:
- **AUC**: ROC曲线下面积
- **灵敏度**: 病变检出率
- **特异度**: 正常样本识别率

**次要终点**:
- **PPV**: 阳性预测值
- **NPV**: 阴性预测值
- **活检率**: 需要活检的患者比例
- **NRI (Net Reclassification Improvement)**: 净重分类改善
- **IDI (Integrated Discrimination Improvement)**: 综合判别改善

#### 统计方法
- **成对ROC曲线比较**: DeLong检验
- **NRI和IDI计算**: 评估分类改善
- **决策曲线分析 (DCA)**: 评估临床效用

## 📊 实验4: 筛查流程优化实验

### 4.1 研究假设

**H0**: 优化后的筛查流程与标准流程在诊断性能上无显著差异  
**H1**: 优化后的筛查流程在保持诊断性能的同时，显著提高效率和患者体验

### 4.2 实验设计

#### 标准流程（当前）
```
初筛 → HPV+TCT → 任一阳性 → 活检
```

#### 优化流程（本研究）
```
初筛 → 多模态AI评估 → 风险分层
  ├─ 高风险 → 直接活检
  ├─ 中风险 → OCT详细检查 → 决策
  └─ 低风险 → 常规随访
```

#### 评估指标

**效率指标**:
- **筛查步骤数**: 平均每个患者需要的检查步骤
- **筛查时间**: 从初筛到决策的平均时间
- **活检率**: 最终需要活检的患者比例

**性能指标**:
- **灵敏度**: 病变检出率
- **特异度**: 正常样本识别率
- **PPV**: 活检阳性预测值

**成本效益指标**:
- **每检出1例病变的成本**: 总成本 / 检出病变数
- **避免的不必要活检数**: 相比标准流程减少的活检数

#### 统计方法
- **配对设计**: 同一患者两种流程的结果对比
- **成本效益分析**: 增量成本效益比 (ICER)

## 📋 综合评估框架

### 临床决策支持系统

#### 风险评分系统
```
综合风险评分 = w1 × OCT风险 + w2 × Colposcopy风险 + w3 × Clinical风险
```

#### 决策阈值优化
- 使用Youden指数找到最优阈值
- 使用决策曲线分析找到临床最优阈值
- 考虑不同临床场景（筛查 vs 诊断）

### 亚组分析

#### 按年龄分层
- <30岁
- 30-50岁
- >50岁

#### 按HPV类型分层
- HPV16/18
- 其他高危型
- 低危型

#### 按TCT结果分层
- NILM
- ASC-US
- LSIL/HSIL

## 🔬 创新性实验设计

### 创新点1: 动态风险分层

**传统方法**: 固定阈值（如HPV+或TCT异常即活检）  
**创新方法**: 基于多模态AI的动态风险评分，实现精准分层

**实验验证**:
- 对比固定阈值 vs 动态阈值
- 评估不同风险层的实际病变率
- 验证风险分层的准确性

### 创新点2: 多模态融合的决策支持

**传统方法**: 单一或简单联合（HPV或TCT）  
**创新方法**: OCT + Colposcopy + Clinical的深度融合

**实验验证**:
- 消融实验：评估各模态的贡献
- 模态重要性分析
- 缺失模态的鲁棒性测试

### 创新点3: 临床工作流程优化

**传统方法**: 线性流程（初筛→检查→活检）  
**创新方法**: 智能分流（风险分层→差异化管理）

**实验验证**:
- 流程效率对比
- 患者体验评估
- 成本效益分析

## 📊 样本量计算

### 实验1: 活检率降低
- **主要终点**: 活检率降低30%
- **假设**: 对照组活检率60%，实验组42%
- **样本量**: 每组至少200例HPV+患者（α=0.05, power=0.8）

### 实验2: OCT灵敏度提升
- **主要终点**: 灵敏度从75%提升到85%
- **样本量**: 至少150例病变患者（α=0.05, power=0.8）

### 实验3: 筛查方案对比
- **主要终点**: AUC提升0.05
- **样本量**: 至少300例患者（α=0.05, power=0.8）

## 📈 预期结果

### 实验1预期
- 活检率降低: **35-45%**
- 灵敏度保持: **≥95%**（非劣效）
- PPV提升: **+10-15%**

### 实验2预期
- OCT灵敏度: **85-90%**（vs 传统75%）
- OCT AUC: **0.85-0.90**（vs 传统0.75）

### 实验3预期
- 多模态AI AUC: **0.85-0.90**
- vs HPV+TCT: AUC提升 **+0.05-0.10**
- vs 单独TCT: AUC提升 **+0.10-0.15**

### 实验4预期
- 筛查步骤减少: **20-30%**
- 活检率降低: **30-40%**
- 成本效益比: **提升25-35%**
