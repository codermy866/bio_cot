# 注意力坍塌问题修复总结

## 🔍 问题根源

**现象**: 注意力均值从Epoch 1的0.5087急剧下降到Epoch 27+的0.0000

**根本原因**:
1. **稀疏损失过强**: `lambda_sparse=0.05`导致模型学习将注意力推向0
2. **无下界保护**: 注意力值可以无限接近0，导致完全坍塌
3. **熵损失权重过大**: 当注意力值很小时，稀疏损失仍然很强

---

## ✅ 修复方案

### 1. 添加注意力下界保护 (`visual_notes.py`)

```python
# 在sigmoid后添加下界保护
min_attn = 0.01  # 最小注意力值（1%），确保不会完全为0
attn_map = torch.clamp(attn_map, min=min_attn, max=1.0)  # 硬下界
```

**效果**: 确保注意力值不会完全为0，保持梯度流动

### 2. 调整稀疏损失计算 (`bio_cot_v3.py`)

```python
# 如果注意力已经过度稀疏（<0.01），降低稀疏损失权重
if attn_mean_oct < 0.01:
    sparse_loss_oct = 0.3 * entropy_oct + 0.1 * l1_oct  # 降低权重
else:
    sparse_loss_oct = 0.5 * entropy_oct + 0.2 * l1_oct  # 正常权重（已降低）
```

**效果**: 当注意力过度稀疏时，减少惩罚，允许恢复

### 3. 降低稀疏损失权重 (`config.py`)

```python
lambda_sparse: float = 0.02  # 从0.05降低到0.02
```

**效果**: 减少稀疏损失在总损失中的比重
