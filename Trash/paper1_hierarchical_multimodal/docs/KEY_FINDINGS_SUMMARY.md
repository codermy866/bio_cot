# 训练效果影响因素 - 关键发现总结

## 🎯 核心发现

### 1. 类别不平衡是最大问题 ⚠️

**数据分布**:
- 类别0: 530 (训练) / 133 (测试) = 67.5%
- 类别1: 255 (训练) / 67 (测试) = 32.5%
- **比例约2:1，严重不平衡**

**影响**:
- 模型严重偏向多数类
- 当前ACC和AUC不高的主要原因
- 少数类召回率低

**解决方案**:
- Focal Loss: gamma=3-5, alpha=0.33
- 类别权重: [1.0, 2.08]
- 数据重采样

---

### 2. Contrastive Loss未生效 ⚠️

**问题**: Loss始终为0

**根本原因**:
- Batch size太小（4），每个batch正样本对太少
- 类别不平衡加剧了这个问题
- 实现中当无正样本对时返回的损失太小

**解决方案**:
- 增加batch size到8-16
- 修复实现：添加跨模态对齐损失
- 使用Memory Bank

---

### 3. Backbone选择确实重要 ✅

**对比结果**:
- ViT: Epoch 1 AUC=0.5825（更好）
- ResNet: Epoch 1 AUC=0.4028（较差）

**结论**:
- ViT的全局注意力更适合医学图像
- 但需要更强的正则化（数据集小）

---

### 4. 训练稳定性问题 ⚠️

**ResNet出现NaN**:
- 可能原因：梯度爆炸、BatchNorm不稳定
- 影响：训练中断，性能下降

**解决方案**:
- 更严格的梯度裁剪
- 使用GroupNorm
- 分层学习率

## 💡 关键洞察

1. **Backbone重要，但不是最重要的**
   - ViT确实比ResNet好，但差距不是最大的
   - 类别不平衡和Contrastive Loss的影响更大

2. **数据质量 > 模型架构**
   - 类别不平衡是数据层面的问题
   - 需要优先解决

3. **训练策略同样重要**
   - 学习率、batch size、正则化都很关键
   - 需要系统性的优化

4. **多因素协同作用**
   - 单独优化某个因素效果有限
   - 需要综合考虑和平衡
