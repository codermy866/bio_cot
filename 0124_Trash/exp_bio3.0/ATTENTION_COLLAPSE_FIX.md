# 注意力坍塌问题修复说明

## 🔍 问题分析

### 现象
从训练日志观察到：
- **Epoch 1**: 注意力均值 OCT=0.5087, Colpo=0.5285（正常）
- **Epoch 2**: 注意力均值 OCT=0.0064, Colpo=0.0068（急剧下降）
- **Epoch 3**: 注意力均值 OCT=0.0016, Colpo=0.0024（继续下降）
- **Epoch 27+**: 注意力均值 OCT=0.0000, Colpo=0.0000（完全坍塌）

### 根本原因

1. **稀疏损失过强**：
   - 稀疏损失鼓励注意力值变小（稀疏化）
   - 当`lambda_sparse=0.05`时，稀疏损失权重过大
   - 训练过程中，模型学习到将注意力值推向0来最小化稀疏损失

2. **没有下界保护**：
   - 注意力值通过sigmoid归一化到[0,1]，但没有下界保护
   - 当注意力值接近0时，梯度可能消失，导致无法恢复

3. **熵损失计算问题**：
   - 当注意力值很小时，归一化后的分布可能不稳定
   - 熵损失可能无法有效防止完全坍塌

---

## ✅ 修复方案

### 1. 添加注意力下界保护（`visual_notes.py`）

```python
# 在sigmoid后添加下界保护
min_attn = 0.01  # 最小注意力值（1%），确保不会完全为0
attn_map = torch.clamp(attn_map, min=min_attn, max=1.0)  # 硬下界
```

**效果**：
- 确保注意力值不会完全为0
- 保持梯度流动，允许模型恢复
- 防止注意力完全坍塌

### 2. 调整稀疏损失计算（`bio_cot_v3.py`）

```python
# 如果注意力已经过度稀疏（<0.01），降低稀疏损失权重
if attn_mean_oct < 0.01:
    sparse_loss_oct = 0.3 * entropy_oct + 0.1 * l1_oct  # 降低权重
else:
    sparse_loss_oct = 0.5 * entropy_oct + 0.2 * l1_oct  # 正常权重（已降低）
```

**效果**：
- 当注意力已经过度稀疏时，减少稀疏损失的惩罚
- 允许模型恢复注意力值
- 更温和的稀疏化策略

### 3. 降低稀疏损失权重（`config.py`）

```python
lambda_sparse: float = 0.02  # 从0.05降低到0.02
```

**效果**：
- 减少稀疏损失在总损失中的比重
- 防止过度稀疏化
- 平衡稀疏性和特征保留
