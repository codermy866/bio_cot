# 类别不平衡激进修复方案

## 📊 问题分析

### 当前问题
从最新训练结果看，模型严重偏向阴性类（多数类）：
- **阴性类 (Negative)**: 
  - Precision: 0.84
  - Recall: 0.96 ⚠️ (几乎全部预测为阴性)
  - F1-score: 0.90
- **阳性类 (Positive)**: 
  - Precision: 0.36
  - Recall: 0.11 ⚠️ (只有11%被正确识别)
  - F1-score: 0.17

### 数据分布
- **训练集**: 阴性=1034, 阳性=213 (比例 **4.85:1**)
- **验证集**: 阴性=222, 阳性=45 (比例 **4.93:1**)

这是**严重的类别不平衡**问题！

---

## 🔧 激进修复方案

### 1. **加权采样器 (WeightedRandomSampler)** ⭐⭐⭐
**原理**: 在采样时给少数类样本更高权重，确保每个batch都有足够的少数类样本

**实现**:
```python
from torch.utils.data import WeightedRandomSampler

# 计算每个样本的权重
sample_weights = []
for i in range(len(train_dataset)):
    label = train_dataset[i]['label'].item()
    weight = pos_weight_ratio if label == 1 else 1.0
    sample_weights.append(weight)

# 创建加权采样器
sampler = WeightedRandomSampler(
    weights=sample_weights,
    num_samples=len(train_dataset),
    replacement=True  # 允许重复采样
)
```

**效果**: 
- ✅ 每个batch中少数类样本比例显著提升
- ✅ 模型能更频繁地看到少数类样本
- ✅ 减少模型对多数类的偏向

---

### 2. **更激进的类别权重** ⭐⭐
**原理**: 直接使用逆频率比，给少数类更高的损失权重

**实现**:
```python
# 之前: pos_weight_ratio = min(np.sqrt(neg_count / pos_count) * 1.5, 3.0)  # 约3.0
# 现在: pos_weight_ratio = min(imbalance_ratio * 0.8, 5.0)  # 约3.88，最大5.0
pos_weight_ratio = min(imbalance_ratio * 0.8, 5.0)
class_weights = torch.FloatTensor([1.0, pos_weight_ratio])
```

**效果**:
- ✅ 少数类样本的损失权重提升约30%
- ✅ 模型更关注少数类样本

---

### 3. **增加Focal Loss的gamma值** ⭐⭐
**原理**: gamma值越高，越关注难分类样本（特别是少数类）

**实现**:
```python
# 之前: gamma=2.0
# 现在: gamma=3.0
criterion = FocalLoss(alpha=focal_alpha, gamma=3.0, label_smoothing=0.1)
```

**效果**:
- ✅ 更关注难分类的少数类样本
- ✅ 减少对简单多数类样本的关注

---

### 4. **调整决策阈值** ⭐⭐⭐
**原理**: 默认阈值0.5对不平衡数据不够，降低阈值更倾向于预测阳性

**实现**:
```python
# 之前: preds = torch.max(logits, 1)[1]  # 默认阈值0.5
# 现在: 
adjusted_threshold = 0.35
probs = torch.softmax(logits, dim=1)
preds = (probs[:, 1] > adjusted_threshold).long()
```

**效果**:
- ✅ 更倾向于预测阳性类
- ✅ 提升阳性类的召回率
- ⚠️ 可能略微降低精确率，但整体F1-score应该提升

## 📝 技术细节

### 加权采样器的工作原理
- 每个样本被选中的概率 = 样本权重 / 总权重
- 少数类样本权重更高，被选中的概率更高
- `replacement=True` 允许重复采样，确保每个batch都有足够的少数类样本

### Focal Loss的gamma参数
- gamma=0: 退化为标准交叉熵
- gamma=2.0: 适度关注难样本
- gamma=3.0: 更关注难样本（当前设置）
- gamma越高，对难样本的关注越强，但可能导致训练不稳定

### 决策阈值的影响
- 阈值越低，越倾向于预测阳性
- 阈值=0.5: 标准阈值（对不平衡数据不够）
- 阈值=0.35: 更倾向于预测阳性（当前设置）
- 可以通过验证集上的F1-score来选择最佳阈值
