# 分类阈值（Threshold）详解

## 📊 什么是阈值？

### 基本概念

**阈值（Threshold）**是二分类问题中，用来决定模型预测结果的一个**临界值**。

### 简单理解

想象一下：
- 模型输出的是**概率值**（0到1之间）
- 例如：模型预测某个样本是"阳性"的概率是 **0.65**
- **阈值**就是判断这个概率是否足够高的**分界线**

### 具体例子

```
模型输出概率 = 0.65

如果阈值 = 0.5:
  → 0.65 > 0.5 → 预测为"阳性" ✅

如果阈值 = 0.7:
  → 0.65 < 0.7 → 预测为"阴性" ❌
```

---

## 🎯 为什么需要阈值？

### 1. **模型输出的是概率，不是类别**

#### 模型实际输出
```
模型输出: [0.3, 0.7]  # 表示：阴性概率30%，阳性概率70%
```

#### 我们需要的是类别
```
最终预测: "阳性" 或 "阴性"
```

#### 阈值的作用
```
如果 阳性概率 > 阈值:
    预测为"阳性"
否则:
    预测为"阴性"
```

### 2. **不同应用场景需要不同的阈值**

#### 医疗诊断（假阴性代价高）
- **目标**: 不能漏诊（假阴性很危险）
- **策略**: 降低阈值（例如0.3）
- **结果**: 更多样本被预测为阳性，减少漏诊

#### 垃圾邮件过滤（假阳性代价高）
- **目标**: 不能误判正常邮件（假阳性很烦人）
- **策略**: 提高阈值（例如0.9）
- **结果**: 只有非常确定才判为垃圾邮件

#### 平衡场景
- **目标**: 平衡精确率和召回率
- **策略**: 使用中等阈值（例如0.5）
- **结果**: 在精确率和召回率之间平衡

## 🔍 阈值与性能指标的关系

### ROC曲线和AUC

#### ROC曲线
- **X轴**: 假阳性率（FPR）
- **Y轴**: 真阳性率（TPR）
- **曲线**: 不同阈值下的TPR和FPR

#### AUC（曲线下面积）
- **含义**: 模型在所有阈值下的平均性能
- **特点**: **不受阈值影响**
- **作用**: 衡量模型的**排序能力**

### 精确率-召回率曲线（PR曲线）

#### PR曲线
- **X轴**: 召回率（Recall）
- **Y轴**: 精确率（Precision）
- **曲线**: 不同阈值下的精确率和召回率

#### AP（平均精确率）
- **含义**: PR曲线下的面积
- **特点**: **受阈值影响**
- **作用**: 衡量模型在特定阈值下的性能

### 为什么AUC高但F1低？

```
AUC = 79.80% ✅ (高)
  → 说明模型在所有阈值下都有很好的排序能力
  → 不受阈值影响

F1 = 56.67% ⚠️ (低，阈值=0.5)
  → 说明在阈值0.5下，精确率和召回率的平衡不好
  → 受阈值影响很大

解决方案: 找到最优阈值（0.580）
  → F1提升到63.33% ✅
```

## 🎯 如何选择最优阈值？

### 方法1: 最大化F1分数

```python
from sklearn.metrics import f1_score

best_f1 = 0
best_threshold = 0.5

for threshold in np.arange(0.3, 0.8, 0.01):
    predictions = (probabilities >= threshold).astype(int)
    f1 = f1_score(true_labels, predictions)
    
    if f1 > best_f1:
        best_f1 = f1
        best_threshold = threshold

print(f"最优阈值: {best_threshold}, F1: {best_f1}")
```

### 方法2: Youden's J统计量

```python
from sklearn.metrics import roc_curve

fpr, tpr, thresholds = roc_curve(true_labels, probabilities)
# Youden's J = TPR - FPR
J = tpr - fpr
optimal_idx = np.argmax(J)
optimal_threshold = thresholds[optimal_idx]
```

### 方法3: 平衡精确率和召回率

```python
from sklearn.metrics import precision_recall_curve

precision, recall, thresholds = precision_recall_curve(true_labels, probabilities)
# 找到精确率和召回率最接近的点
f1_scores = 2 * (precision * recall) / (precision + recall)
optimal_idx = np.argmax(f1_scores)
optimal_threshold = thresholds[optimal_idx]
```

## 🔧 在代码中如何使用阈值？

### 训练阶段

```python
# 模型输出概率
probabilities = model(inputs)  # [batch_size, 2]
probs_positive = probabilities[:, 1]  # 阳性概率

# 使用阈值进行预测
threshold = 0.580  # 最优阈值
predictions = (probs_positive >= threshold).astype(int)
```

### 验证阶段

```python
# 计算不同阈值下的性能
for threshold in [0.3, 0.4, 0.5, 0.6, 0.7]:
    predictions = (probs_positive >= threshold).astype(int)
    accuracy = accuracy_score(labels, predictions)
    f1 = f1_score(labels, predictions)
    print(f"阈值={threshold}: 准确率={accuracy:.4f}, F1={f1:.4f}")
```

```python
# 加载最优阈值
with open('logs/optimal_threshold.txt', 'r') as f:
    optimal_threshold = float(f.read().strip())

# 使用最优阈值进行预测
```

## 📝 总结

### 阈值是什么？
- **定义**: 判断模型预测概率是否足够高的临界值
- **作用**: 将概率转换为类别预测
- **范围**: 通常在0到1之间

### 为什么需要阈值？
1. **模型输出概率，我们需要类别**
2. **不同应用场景需要不同的阈值**
3. **阈值直接影响分类结果和性能**

### 如何选择最优阈值？
1. **最大化F1分数**（我们使用的方法）
2. **Youden's J统计量**
3. **平衡精确率和召回率**

### 在我们的项目中
- **默认阈值**: 0.5（不适合）
- **最优阈值**: 0.580（已应用）
- **改进效果**: 准确率+20.24%，F1+6.67%

---

**关键理解**: 阈值是连接模型概率输出和最终分类决策的桥梁。选择合适的阈值可以显著提升模型的实际性能！
