# 层次化多粒度多模态融合方法

## 🎯 方法概述

本文提出了一种**层次化多粒度多模态融合方法**，用于宫颈病变的智能诊断。

### 核心思想

传统多模态融合方法简单地将不同模态的特征拼接或加权平均，忽略了：
1. **不同粒度的信息**：局部细节 vs 全局语义
2. **模态间的互补性**：不同模态在不同粒度上的贡献不同
3. **样本间的差异性**：不同样本的模态重要性不同

### 解决方案

我们提出**4层层次化架构**：
1. **Level 1**: 多粒度特征提取（局部、全局、时序、空间）
2. **Level 2**: 跨模态多粒度对齐
3. **Level 3**: 多粒度融合
4. **Level 4**: 层次化决策

## 📐 方法架构

```
输入
├── OCT图像序列 [B, 48, 3, 224, 224]
├── Colposcopy图像 [B, 3, 3, 224, 224]
└── 临床特征 [B, 8]

↓ Level 1: 多粒度特征提取

OCT多粒度特征:
├── 局部特征 [B, 768]  ← 细粒度（病变边缘、纹理）
├── 全局特征 [B, 768]  ← 中粒度（整体病变分布）
└── 时序特征 [B, 768]  ← 时序粒度（动态变化）

Colposcopy多粒度特征:
├── 局部特征 [B, 768]  ← 细粒度
├── 全局特征 [B, 768]  ← 中粒度
└── 空间特征 [B, 768]  ← 空间粒度（多视图关系）

临床特征:
├── 语义特征 [B, 768]  ← 语义粒度
└── 统计特征 [B, 768]  ← 统计粒度

↓ Level 2: 跨模态多粒度对齐

对齐后的特征:
├── 局部对齐特征 [B, 768]  ← OCT局部 ↔ Colposcopy局部
├── 全局对齐特征 [B, 768]  ← OCT全局 ↔ Colposcopy全局
└── 语义对齐特征 [B, 768]  ← 临床语义 ↔ 图像特征

↓ Level 3: 多粒度融合

融合后的特征:
├── 细粒度融合 [B, 768]
├── 中粒度融合 [B, 768]
└── 粗粒度融合 [B, 768]

↓ Level 4: 层次化决策

最终输出:
└── 预测结果 [B, 2] + 不确定性
```

## 🔬 技术细节

### 1. 多粒度特征提取

#### 局部特征编码器
- **目的**：提取细粒度的局部特征（如病变边缘、纹理等）
- **方法**：使用小感受野的卷积（3×3）
- **输出**：保持空间信息的特征图

#### 全局特征编码器
- **目的**：提取全局的语义特征（如整体病变分布、形状等）
- **方法**：使用大感受野的卷积（7×7）+ 全局池化
- **输出**：全局语义特征

#### 时序特征编码器（OCT）
- **目的**：提取时序动态特征
- **方法**：LSTM或Transformer
- **输出**：时序特征

#### 空间特征编码器（Colposcopy）
- **目的**：提取多视图的空间关系
- **方法**：自注意力机制
- **输出**：空间关系特征

### 2. 跨模态多粒度对齐

#### 对齐机制
- **局部-局部对齐**：OCT局部特征 ↔ Colposcopy局部特征
- **全局-全局对齐**：OCT全局特征 ↔ Colposcopy全局特征
- **语义-视觉对齐**：临床语义特征 ↔ 图像特征

#### 对齐方法
使用交叉注意力机制，将不同模态的特征对齐到统一空间。

### 3. 多粒度融合

#### 细粒度融合
融合局部特征，捕获细节信息。

#### 中粒度融合
融合全局特征，捕获语义信息。

#### 粗粒度融合
融合语义特征，捕获高级抽象。

### 4. 层次化决策

结合多粒度特征进行分类，不同粒度特征有不同的权重。

## 🎯 创新点

1. **层次化架构**：4层架构，从细粒度到粗粒度
2. **多粒度表示**：同时提取局部、全局、时序、空间特征
3. **跨模态对齐**：显式学习模态间的对齐关系
4. **自适应权重**：根据样本特征质量动态调整权重
