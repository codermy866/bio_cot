# 阴性预测值为0问题 - 修复方案总结

## 🔧 已实施的修复

### 1. **增强类别权重计算** ✅
- **位置**: `train_bio_cot_xiangyang.py` 第325-340行
- **修改**: 使用更激进的权重计算方法
  - 标准权重：`total_samples / (num_classes * class_counts)`
  - 增强权重：直接使用逆频率比，至少3倍权重
  - `pos_weight_ratio = max(neg_count / pos_count, 3.0)`
- **效果**: 给少数类（阳性）更高的权重，平衡训练

### 2. **使用Focal Loss替代CrossEntropyLoss** ✅
- **位置**: `train_bio_cot_xiangyang.py` 第427-431行
- **修改**: 
  - 从 `nn.CrossEntropyLoss(weight=class_weights)` 
  - 改为 `FocalLoss(alpha=focal_alpha, gamma=2.5, label_smoothing=0.1)`
- **参数**:
  - `alpha`: [1.0, pos_weight_ratio] - 少数类权重更高
  - `gamma`: 2.5 - 关注难分类样本
  - `label_smoothing`: 0.1 - 防止过拟合
- **效果**: Focal Loss对类别不平衡更鲁棒，自动关注难分类样本

### 3. **改进Early Stopping策略** ✅
- **位置**: `train_bio_cot_xiangyang.py` 第449-524行
- **修改**: 
  - 从基于 `val_acc` 选择最佳模型
  - 改为基于 `F1-score * 0.7 + AUC * 0.3` 的加权组合
- **新增指标**:
  - `val_f1`: 宏平均F1-score
  - `val_f1_pos`: 阳性类F1-score
- **效果**: 避免选择偏向多数类的模型，选择真正平衡的模型

### 4. **增强验证函数** ✅
- **位置**: `train_bio_cot_xiangyang.py` 第174-220行
- **修改**: 在 `validate()` 函数中添加F1-score计算
- **新增返回**: `f1`, `f1_pos`
- **效果**: 更全面地评估模型性能

### 5. **改进日志和监控** ✅
- **位置**: `train_bio_cot_xiangyang.py` 第484-492行
- **修改**: 
  - 打印F1-score和阳性类F1-score
  - 日志中记录所有关键指标
