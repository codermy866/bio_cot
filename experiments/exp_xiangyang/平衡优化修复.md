# 类别平衡优化和字体修复

## 🔍 问题分析

从最新训练结果来看：
- **阳性类**: precision=0.23, recall=0.78, f1=0.36 ✅ 召回率提升
- **阴性类**: precision=0.91, recall=0.48, f1=0.63 ❌ 召回率下降

**问题根源**: 阳性类权重过高（4.85倍），导致模型过度预测阳性，从而降低了阴性的召回率。

## 🔧 修复方案

### 1. **平衡类别权重** ✅

**修改前**:
```python
pos_weight_ratio = max(neg_count / pos_count, 3.0)  # 直接使用逆频率比，至少3倍
```

**修改后**:
```python
# 使用平方根来平衡，避免过度偏向少数类
pos_weight_ratio = min(np.sqrt(neg_count / pos_count) * 1.5, 3.0)  # 限制最大权重为3.0
```

**效果**:
- 对于4.85:1的不平衡，新方法计算：`sqrt(4.85) * 1.5 ≈ 3.3`，但限制为3.0
- 相比之前的4.85，权重更平衡，不会过度偏向阳性类

### 2. **降低Focal Loss的gamma** ✅

**修改前**:
```python
criterion = FocalLoss(alpha=focal_alpha, gamma=2.5, label_smoothing=0.1)
```

**修改后**:
```python
criterion = FocalLoss(alpha=focal_alpha, gamma=2.0, label_smoothing=0.1)
```

**效果**:
- gamma从2.5降到2.0，更平衡地关注两类
- 避免过度关注难样本，减少对少数类的过度偏向

### 3. **修复混淆矩阵字体问题** ✅

**修改前**:
```python
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', 
            xticklabels=['阴性', '阳性'], 
            yticklabels=['阴性', '阳性'])
plt.ylabel('真实标签')
plt.xlabel('预测标签')
plt.title('混淆矩阵')
```

**修改后**:
```python
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', 
            xticklabels=['Negative (0)', 'Positive (1)'], 
            yticklabels=['Negative (0)', 'Positive (1)'],
            cbar_kws={'label': 'Count'})
plt.ylabel('True Label', fontsize=12)
plt.xlabel('Predicted Label', fontsize=12)
plt.title('Confusion Matrix', fontsize=14, fontweight='bold')
```

**效果**:
- 使用英文标签，避免中文字体显示问题
- 同时显示类别名称和数字（0/1），更清晰

### 4. **统一分类报告标签** ✅

**修改前**:
```python
target_names=['阴性', '阳性']
```

**修改后**:
```python
target_names=['Negative (0)', 'Positive (1)']
```

**效果**:
- 所有输出统一使用英文标签
- 避免字体显示问题
