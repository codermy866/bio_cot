# 实验方法详细说明

## 1. 数据集

### 1.1 数据集描述
本研究使用来自5个医疗中心的多模态宫颈病变筛查数据集（5centers_multi），包含以下三种模态：

- **OCT（光学相干断层扫描）图像**：每个患者包含120张OCT图像，覆盖宫颈的多个扫描点（12个点，每个点10帧），图像分辨率为224×224像素。
- **Colposcopy（阴道镜）图像**：每个患者包含3张阴道镜图像，分辨率224×224像素。
- **临床特征**：7维特征向量，包括：
  - 年龄（归一化到0-1）
  - HPV检测结果（0/1）
  - TCT检测结果（5维one-hot编码）

### 1.2 数据划分
- **训练集**：785个患者样本
- **验证集**：200个患者样本
- **任务**：二分类（正常 vs. 异常）

### 1.3 数据预处理
- OCT图像：从每个患者的120张原始图像中完整加载，不使用缓存机制以确保所有图像参与训练
- Colposcopy图像：加载3张图像
- 数据增强：训练时使用随机水平翻转、颜色抖动、随机裁剪等增强策略
- 归一化：使用ImageNet均值和标准差进行归一化

## 2. 模型架构

### 2.1 整体框架
本研究提出**增强因果约束贝叶斯CLIP（Enhanced Causal Bayesian CLIP）**框架，包含以下核心组件：

1. **多模态特征提取器**：基于Swin Transformer-Tiny（Swin-T）的图像编码器
2. **贝叶斯编码器**：为每个模态输出均值和方差，实现不确定性量化
3. **可学习因果图发现模块**：动态学习模态间的因果关系
4. **不确定性分解模块**：区分认知不确定性和偶然不确定性
5. **跨模态融合与分类器**：基于因果约束的多头注意力融合

### 2.2 特征提取器

#### 2.2.1 OCT编码器
- **Backbone**：Swin-T（`swin_tiny_patch4_window7_224`）
- **输入**：`[B, 120, 3, 224, 224]`（批次大小B，120帧OCT图像）
- **输出**：`[B, 768]`（768维特征向量）
- **微调策略**：冻结大部分层，仅解冻最后2层进行微调，可训练参数约52.64M/55.04M

#### 2.2.2 Colposcopy编码器
- **Backbone**：Swin-T（`swin_tiny_patch4_window7_224`）
- **输入**：`[B, 3, 3, 224, 224]`（3张阴道镜图像）
- **输出**：`[B, 768]`（768维特征向量）
- **微调策略**：与OCT编码器相同

#### 2.2.3 临床特征投影
- **输入**：`[B, 7]`（7维临床特征）
- **投影层**：线性层 `Linear(7, 768)`
- **输出**：`[B, 768]`（投影到与图像特征相同的维度）

### 2.3 贝叶斯编码器

每个模态（OCT、Colposcopy、Clinical）使用独立的贝叶斯编码器，实现变分推断：

**架构**：
```
输入特征 [B, 768]
    ↓
均值分支：Linear(768, 768) → 输出 μ [B, 768]
方差分支：Linear(768, 768) → Softplus → 输出 log(σ²) [B, 768]
    ↓
重参数化采样：z = μ + ε·σ, ε ~ N(0,1)
    ↓
输出：采样特征 [B, 768]
```

**关键特性**：
- 训练时：使用重参数化技巧进行采样，实现端到端训练
- 推理时：直接使用均值特征，提高稳定性
- 不确定性量化：通过方差估计模型对预测的不确定性

### 2.4 可学习因果图发现模块

#### 2.4.1 架构设计
可学习因果图模块（`LearnableCausalGraph`）动态发现三个模态（OCT、Colposcopy、Clinical）之间的因果关系：

**输入**：三个模态的特征列表 `[oct_feat, colpo_feat, clinical_feat]`，每个为 `[B, 768]`

**因果发现网络**：
```
拼接特征 [B, 2304] (768×3)
    ↓
Linear(2304, 512) → LayerNorm → GELU → Dropout(0.1)
    ↓
Linear(512, 256) → LayerNorm → GELU → Dropout(0.1)
    ↓
Linear(256, 9) → Sigmoid
    ↓
重塑为 [B, 3, 3] 因果邻接矩阵
```

**可学习权重矩阵**：
- 参数：`nn.Parameter([3, 3])`，初始化为小随机值
- 作用：与数据驱动的因果发现结果结合，增强可解释性

#### 2.4.2 DAG约束
为确保因果图是有向无环图（DAG），采用以下策略：

1. **上三角矩阵约束**：强制因果矩阵为上三角形式，避免循环
2. **NOTEARS风格惩罚**：使用矩阵指数迹的近似来惩罚循环结构
   ```
   penalty = ReLU(trace(exp(A ∘ A)) - num_modalities)²
   ```
   其中A是因果邻接矩阵，`∘`表示逐元素乘积

#### 2.4.3 稀疏正则化
鼓励因果图的稀疏性，减少虚假因果关系：
```
sparsity_penalty = mean(|causal_adj|)
```

#### 2.4.4 干预反馈机制
支持伪干预训练，通过干预mask抑制被干预模态的因果出边：
- **干预mask**：`[B, 3]`，1表示该模态被干预
- **干预惩罚**：对被干预模态的出边进行额外惩罚，增强模型对干预的敏感性

#### 2.4.5 先验知识融合
结合医学领域先验知识：
- **硬约束**：Clinical → OCT，Clinical → Colposcopy（必须存在）
- **软约束**：其他因果关系由数据驱动学习

### 2.5 不确定性分解模块

将总不确定性分解为两个组成部分：

#### 2.5.1 认知不确定性（Epistemic Uncertainty）
- **来源**：模型参数的不确定性
- **估计**：基于融合特征的MLP网络
  ```
  融合特征 [B, 768]
      ↓
  Linear(768, 384) → LayerNorm → GELU → Dropout(0.1)
      ↓
  Linear(384, 1) → Softplus
      ↓
  输出：认知不确定性 [B, 1]
  ```

#### 2.5.2 偶然不确定性（Aleatoric Uncertainty）
- **来源**：数据固有的噪声和变异性
- **估计**：基于贝叶斯编码器输出的方差
  ```
  多模态方差 [B, 2304] 或 [B, 768]
      ↓
  平均或投影到 [B, 768]
      ↓
  Linear(768, 384) → LayerNorm → GELU → Dropout(0.1)
      ↓
  Linear(384, 1) → Softplus
      ↓
  输出：偶然不确定性 [B, 1]
  ```

#### 2.5.3 总不确定性
```
total_uncertainty = epistemic + aleatoric
```

### 2.6 跨模态融合与分类

#### 2.6.1 因果约束的注意力融合
1. **因果权重应用**：使用学习到的因果邻接矩阵对模态序列进行加权
   ```
   multimodal_seq = [oct_feat, colpo_feat, clinical_feat]  # [B, 3, 768]
   causal_weights = causal_adj  # [B, 3, 3]
   weighted_seq = causal_weights @ multimodal_seq  # [B, 3, 768]
   ```

2. **多头注意力融合**：
   - 头数：8
   - Dropout：0.1
   - 输出：`[B, 3, 768]` → 平均池化 → `[B, 768]`

#### 2.6.2 特征融合层
```
拼接特征 [B, 2304] (768×3)
    ↓
Linear(2304, 1536) → LayerNorm → GELU → Dropout(0.5)
    ↓
Linear(1536, 768)
    ↓
融合特征 [B, 768]
```

#### 2.6.3 分类器
```
融合特征 [B, 768]
    ↓
Linear(768, 384) → LayerNorm → GELU → Dropout(0.5)
    ↓
Linear(384, 2)
    ↓
分类logits [B, 2]
```

## 3. 损失函数设计

总损失函数由多个组件组成：

### 3.1 分类损失
使用**Focal Loss with Label Smoothing**处理类别不平衡：

```
Focal Loss = -α(1-p_t)^γ log(p_t)
```

其中：
- `p_t`：模型对真实类别的预测概率
- `α`：类别权重（自动平衡）
- `γ`：聚焦参数（默认2.0）
- **Label Smoothing**：0.01（减少过拟合）

### 3.2 KL散度损失
正则化贝叶斯编码器的后验分布，防止方差过大：

```
KL_loss = 0.5 * Σ(σ² + μ² - 1 - log(σ²))
```

权重：`λ_kl = 0.001`（已优化降低）

### 3.3 对比损失（可选）
InfoNCE损失用于增强跨模态对齐：

```
contrastive_loss = -log(exp(sim(oct, colpo)/τ) / Σ exp(sim(oct, colpo_i)/τ))
```

在当前最优配置中，对比损失权重设为0（`contrastive_weight=0`），以降低总损失。

### 3.4 因果正则化损失

#### 3.4.1 DAG惩罚
```
dag_penalty = λ_dag * ReLU(trace(exp(A ∘ A)) - 3)²
```
权重：`λ_dag = 0.02`

#### 3.4.2 稀疏惩罚
```
sparsity_penalty = λ_sparse * mean(|causal_adj|)
```
权重：`λ_sparse = 0.0002`

#### 3.4.3 干预惩罚
```
intervention_penalty = λ_inter * mean(intervened_edges)
```
权重：`λ_inter = 0.01`

#### 3.4.4 总因果损失
```
causal_loss = λ_causal * (dag_penalty + sparsity_penalty + intervention_penalty)
```
总权重：`λ_causal = 0.001`

### 3.5 总损失
```
L_total = L_focal + λ_kl * L_kl + λ_contrastive * L_contrastive + L_causal
```

**最优权重配置**：
- `λ_kl = 0.001`
- `λ_contrastive = 0`（关闭）
- `λ_causal = 0.001`
- `label_smoothing = 0.01`

## 4. 训练策略

### 4.1 优化器设置
- **优化器**：AdamW
- **学习率**：3e-4
- **权重衰减**：5e-4
- **Beta参数**：(0.9, 0.999)

### 4.2 学习率调度
- **策略**：Cosine Annealing
- **T_max**：100（总epoch数）
- **eta_min**：1e-6

### 4.3 训练配置
- **批次大小**：24（针对120帧OCT优化，防止OOM）
- **总epoch数**：100
- **混合精度训练**：关闭（`--no_amp`），使用FP32以提高数值稳定性
- **梯度裁剪**：最大梯度范数1.0

### 4.4 特征提取器微调
- **策略**：部分微调
- **解冻层数**：最后2层
- **可训练参数**：52.64M / 55.04M（约95.6%）

### 4.5 伪干预训练
- **概率**：50%的batch随机选择一个模态进行干预
- **目的**：增强模型对因果关系的敏感性，减少虚假相关

### 4.6 早停策略
- **监控指标**：验证集损失
- **Patience**：5个epoch
- **保存策略**：基于验证集AUC保存最佳模型

## 5. 评估指标

### 5.1 分类性能指标
- **准确率（Accuracy）**
- **AUC-ROC**
- **F1-Score**
- **精确率（Precision）**
- **召回率（Recall / Sensitivity）**
- **特异性（Specificity）**

### 5.2 最优阈值选择
使用**Youden指数**选择最优分类阈值：
```
Youden Index = Sensitivity + Specificity - 1
optimal_threshold = argmax(Youden Index)
```

### 5.3 临床指标
- **阳性预测值（PPV）**
- **阴性预测值（NPV）**
- **阳性似然比（LR+）**
- **阴性似然比（LR-）**
- **MCC（Matthews Correlation Coefficient）**

### 5.4 不确定性评估
- **总不确定性**：epistemic + aleatoric
- **不确定性校准**：评估预测置信度与实际准确率的一致性
