#### 创新点2: Bayesian Uncertainty Quantification ⭐⭐⭐⭐

**技术描述**:
- **变分推断**: 使用变分自编码器框架学习后验分布
- **重参数化技巧**: 支持端到端训练
- **不确定性估计**: 输出预测置信度

**数学形式化**:

```
变分后验:
  q(z|x) = N(μ(x), σ²(x))

重参数化:
  z = μ(x) + ε · σ(x),  ε ~ N(0, 1)

KL散度正则化:
  L_KL = KL(q(z|x) || p(z))
       = -0.5 * Σ(1 + log(σ²) - μ² - σ²)

不确定性估计:
  uncertainty = sigmoid(Σ KL_i / num_modalities)
```

**创新性评估**:
- ✅ **技术成熟**: 贝叶斯深度学习标准方法
- ✅ **医学价值**: 不确定性量化对临床决策重要
- ⚠️ **创新有限**: 主要是应用而非方法创新

**MICCAI价值**: ⭐⭐⭐⭐ (4/5)

### 2.2 损失函数设计

#### 总损失函数

```python
L_total = L_CE + λ_KL · L_KL + λ_contrast · L_contrast + λ_causal · L_causal
```

#### 损失组件分析

**1. 分类损失 (Cross-Entropy Loss)**
```python
L_CE = CrossEntropyLoss(logits, labels, label_smoothing=0.05)
```
- **作用**: 主要优化目标
- **权重**: 1.0 (基准)
- **评估**: ⭐⭐⭐⭐⭐ (5/5) - 标准且有效

**2. KL散度损失 (KL Divergence Loss)**
```python
L_KL = Σ_i KL(q(z_i|x_i) || p(z_i))
```
- **作用**: 正则化变分后验，防止过拟合
- **权重**: λ_KL = 0.001-0.003
- **评估**: ⭐⭐⭐⭐ (4/5) - 贝叶斯框架必需

**3. 对比损失 (Contrastive Loss)**
```python
L_contrast = InfoNCE(f_oct, f_col, f_clin, temperature=0.07)
```
- **作用**: 学习跨模态对齐
- **权重**: λ_contrast = 0.02-0.05
- **评估**: ⭐⭐⭐⭐ (4/5) - CLIP框架核心

**4. 因果损失 (Causal Loss)**
```python
L_causal = L_DAG + L_sparsity + L_intervention

# DAG惩罚
L_DAG = (trace(exp(A ⊙ A)) - num_modalities)²

# 稀疏正则化
L_sparsity = ||A||_1

# 干预惩罚
L_intervention = MSE(A_intervened, A_original)
```
- **作用**: 确保因果图的合理性和稀疏性
- **权重**: λ_causal = 0.001-0.002
- **评估**: ⭐⭐⭐⭐⭐ (5/5) - 核心创新，需要仔细调优
