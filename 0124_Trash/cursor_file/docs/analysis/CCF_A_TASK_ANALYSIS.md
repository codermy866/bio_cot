## 2. 核心科学问题 (Core Scientific Problems)

### 2.1 科学问题1: 多模态医学诊断的因果结构是什么？

#### 问题定义

**核心问题**: 
- 在医学诊断中，不同模态（OCT、Colposcopy、Clinical）之间的因果关系是什么？
- 这种因果关系是固定的还是个性化的？

**CCF-A要求**:
- ⭐⭐⭐⭐⭐ 需要理论框架定义
- ⭐⭐⭐⭐⭐ 需要数学形式化
- ⭐⭐⭐⭐⭐ 需要理论保证

---

#### 理论框架（CCF-A标准）

**定义1: 医学因果结构（Medical Causal Structure）**

```
设 M = {M_oct, M_col, M_clin} 为三个模态
设 G = (V, E) 为有向无环图（DAG），其中：
  - V = {M_oct, M_col, M_clin, Y} 为节点集合
  - E = {(M_i, M_j) | M_i → M_j} 为有向边集合

医学因果结构 G 满足：
  1. 临床特征 → OCT: Clinical特征影响OCT表现
  2. 临床特征 → Colposcopy: Clinical特征影响Colposcopy表现
  3. OCT, Colposcopy → 诊断: 多模态证据共同决定诊断
```

**理论贡献**: 
- ✅ 定义了医学诊断的因果结构
- ✅ 有严格的数学形式化
- ✅ 符合医学认知

---

**定义2: 个性化因果结构（Personalized Causal Structure）**

```
对于患者 i，其因果结构 G_i 可能不同：
  G_i = f_personalized(X_i, θ)
  
其中：
  - X_i 为患者特征
  - θ 为个性化参数
  - f_personalized 为个性化函数
```

**理论贡献**:
- ✅ 考虑了患者异质性
- ✅ 更符合医学实际
- ✅ 有理论创新

#### 理论框架（CCF-A标准）

**学习理论: 语义-结构统一学习（Semantic-Structure Unified Learning）**

**核心思想**:
- 不是简单组合"语义理解（VLM）"和"结构学习（Causal）"
- 而是"语义和结构在统一理论框架下学习"

**数学形式化**:

```
设 S 为语义空间，C 为因果结构空间
统一学习空间: U = S × C

学习目标:
  min_{θ} L_unified(θ) = L_semantic(θ) + L_structure(θ) + L_coupling(θ)
  
其中:
  - L_semantic: 语义理解损失
  - L_structure: 结构学习损失
  - L_coupling: 语义-结构耦合损失（关键创新）
```

**理论贡献**:
- ✅ 提出统一学习理论
- ✅ 有严格的数学形式化
- ✅ 有理论保证（收敛性）

#### 理论框架（CCF-A标准）

**推理理论: 因果推理引擎（Causal Reasoning Engine）**

**核心思想**:
- 不是简单的特征融合
- 而是基于因果结构的推理过程

**数学形式化**:

```
给定因果结构 G 和观测 X:
  1. 因果证据收集: E = CollectEvidence(X, G)
  2. 因果链推理: C = ReasonChain(E, G)
  3. 诊断决策: Y = Decision(C, G)
  4. 不确定性: U = QuantifyUncertainty(C, G)
```

**理论贡献**:
- ✅ 提出因果推理理论

**问题**:

- 在什么条件下可识别？

**CCF-A要求**:

**理论贡献**:
```
定理1（可识别性）:
  在以下条件下，医学因果结构 G 是可识别的：
    1. 因果忠实性（Causal Faithfulness）
    2. 无混杂（No Confounding）
    3. 足够的样本量
```

---

#### 挑战2: 个性化因果结构的学习

**问题**:
- 如何为每个患者学习个性化因果结构？

**CCF-A要求**:

- ⭐⭐⭐⭐⭐ 需要理论保证

**理论贡献**:
```
定理2（个性化学习）:
  个性化因果结构 G_i 的学习误差界：
    E[L(G_i, G_i^*) ] ≤ O(√(log n / n_i) + λ)
  
  其中：
    - n_i 为患者 i 的样本数
    - λ 为先验知识的正则化项
```

---

#### 挑战3: 因果推理的不确定性量化

**问题**:
- 因果推理中的不确定性如何量化？
- 如何区分结构不确定性和参数不确定性？

**CCF-A要求**:
- ⭐⭐⭐⭐⭐ 需要新的不确定性理论
- ⭐⭐⭐⭐⭐ 需要理论保证

**理论贡献**:
```
定义3（因果不确定性）:
  因果不确定性 U_causal 定义为：
    U_causal = U_structure + U_parameter + U_evidence
  
  其中：
    - U_structure: 因果结构的不确定性
```
