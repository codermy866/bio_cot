## 查看方法

### 1. 查看最新的日志文件（推荐）
```bash
# 查看最新的日志文件
ls -lht experiments/exp_xiangyang/logs/train_bio_cot_multimodal_*.log | head -1

# 实时查看最新日志
tail -f experiments/exp_xiangyang/logs/train_bio_cot_multimodal_*.log
```

### 2. 查看指定日志文件
```bash
# 查看最后50行
tail -50 experiments/exp_xiangyang/logs/train_bio_cot_multimodal_20260106_151827.log

# 查看全部日志
cat experiments/exp_xiangyang/logs/train_bio_cot_multimodal_20260106_151827.log
```

### 3. 查看特定内容
```bash
# 只看epoch信息
grep "Epoch" experiments/exp_xiangyang/logs/train_bio_cot_multimodal_*.log

# 只看验证结果
grep "Val" experiments/exp_xiangyang/logs/train_bio_cot_multimodal_*.log

# 只看保存模型的信息
grep "保存最佳模型" experiments/exp_xiangyang/logs/train_bio_cot_multimodal_*.log
```
