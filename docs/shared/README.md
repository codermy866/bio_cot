# 共享文档文件夹

## 📋 说明

本文件夹包含所有论文共用的文档，包括：
- 论文拆分策略和分析
- 通用的写作指南
- 实验计划和检查清单
- 时间规划

---

## 📂 文档列表

### 论文拆分相关
- `PAPER_SPLITTING_ANALYSIS.md` - 完整的Pipeline分析和拆分方案
- `PAPER_SPLITTING_SUMMARY.md` - 论文拆分策略总结（快速参考）

### 写作指南
- `PAPER_WRITING_GUIDE.md` - 每篇论文的详细写作指南

### 实验相关
- `EXPERIMENT_SUPPLEMENT_CHECKLIST.md` - 需要补充的实验清单
- `COMPLETE_EXPERIMENT_PLAN.md` - 完整实验计划
- `EXPERIMENT_CHECKLIST.md` - 实验检查清单

### 时间规划
- `IMPLEMENTATION_TIMELINE.md` - 12个月的实施时间表

### 发表相关
- `LANCET_PUBLICATION_EXPERIMENT_PLAN.md` - Lancet发表实验计划
- `LANCET_EXPERIMENTS_CHINESE.md` - Lancet实验中文版
- `LANCET_PUBLICATION_ASSESSMENT.md` - Lancet发表评估

---

## 🔗 快速导航

### 想了解论文拆分策略？
→ 阅读 `PAPER_SPLITTING_SUMMARY.md`（快速）或 `PAPER_SPLITTING_ANALYSIS.md`（详细）

### 想开始写论文？
→ 阅读 `PAPER_WRITING_GUIDE.md`，找到对应论文的写作指南

### 想知道需要做什么实验？
→ 阅读 `EXPERIMENT_SUPPLEMENT_CHECKLIST.md`，找到对应论文的实验清单

### 想了解时间规划？
→ 阅读 `IMPLEMENTATION_TIMELINE.md`

---

## 📝 使用建议

1. **首次阅读**：先看 `PAPER_SPLITTING_SUMMARY.md` 了解整体规划
2. **开始写作**：参考 `PAPER_WRITING_GUIDE.md` 中的对应章节
3. **规划实验**：查看 `EXPERIMENT_SUPPLEMENT_CHECKLIST.md`
4. **时间管理**：参考 `IMPLEMENTATION_TIMELINE.md` 安排工作

**提示**：这些文档是通用的，具体到每篇论文的详细文档，请查看对应论文文件夹。
