# The Lancet Primary Care - 统计分析计划

## 📊 统计分析概述

本研究采用多种统计方法，确保结果的科学性和可靠性，符合The Lancet Primary Care的发表要求。

---

## 1. 实验1: 活检率降低实验

### 1.1 主要终点

**活检率降低百分比**
- 计算公式: `(对照组活检率 - 实验组活检率) / 对照组活检率 × 100%`
- 统计方法: **配对t检验** 或 **McNemar检验**
- 显著性水平: α = 0.05

### 1.2 次要终点

**灵敏度非劣效性检验**
- H0: 实验组灵敏度 ≤ 对照组灵敏度 - 5%
- H1: 实验组灵敏度 > 对照组灵敏度 - 5%
- 非劣效性界值: **-5%**
- 统计方法: **单侧Z检验**
- 显著性水平: α = 0.05

**PPV提升**
- 统计方法: **McNemar检验**
- 显著性水平: α = 0.05

### 1.3 样本量计算

- **主要终点**: 活检率降低30%
- **假设**: 对照组60%，实验组42%
- **样本量**: 每组至少200例HPV+患者
- **Power**: 0.8, α = 0.05

---

## 2. 实验2: OCT灵敏度提升实验

### 2.1 主要终点

**OCT灵敏度**
- 统计方法: **ROC曲线分析**
- 比较方法: **DeLong检验**
- 显著性水平: α = 0.05

### 2.2 次要终点

**AUC提升**
- 统计方法: **DeLong检验**
- 95%置信区间: Bootstrap方法

**早期病变检出率**
- 统计方法: **卡方检验** 或 **Fisher精确检验**

### 2.3 样本量计算

- **主要终点**: 灵敏度从75%提升到85%
- **样本量**: 至少150例病变患者
- **Power**: 0.8, α = 0.05

---

## 3. 实验3: 筛查方案对比实验

### 3.1 主要终点

**AUC比较**
- 统计方法: **成对ROC曲线比较（DeLong检验）**
- 多重比较校正: **Bonferroni校正**
- 显著性水平: α = 0.05 / 3 = 0.0167

### 3.2 次要终点

**NRI (Net Reclassification Improvement)**
- 计算公式: NRI = NRI_event + NRI_nonevent
- 统计检验: **Z检验**
- 显著性水平: α = 0.05

**IDI (Integrated Discrimination Improvement)**
- 统计检验: **Z检验**
- 显著性水平: α = 0.05

**决策曲线分析 (DCA)**
- 方法: 计算不同阈值下的净收益
- 可视化: 决策曲线图

### 3.3 样本量计算

- **主要终点**: AUC提升0.05
- **样本量**: 至少300例患者
- **Power**: 0.8, α = 0.05

---

## 4. 实验4: 流程优化实验

### 4.1 主要终点

**筛查效率提升**
- 指标: 筛查步骤数、筛查时间
- 统计方法: **配对t检验**

**成本效益分析**
- 指标: 总成本、人均成本、每检出1例成本
- 统计方法: **成本效益比计算**
- **ICER (Incremental Cost-Effectiveness Ratio)**: 增量成本效益比

### 4.2 次要终点

**诊断性能保持**
- 灵敏度、特异度对比
- 统计方法: **McNemar检验**

### 4.3 样本量计算

- **主要终点**: 成本降低20%
- **样本量**: 至少200例患者
- **Power**: 0.8, α = 0.05

## 6. 多重比较校正

### 6.1 主要终点

- 每个实验的主要终点: **不校正**（预先指定）
- 多个主要终点: **Bonferroni校正**

### 6.2 次要终点

- 探索性分析: **FDR校正**（False Discovery Rate）
- 或 **Bonferroni校正**

## 11. 预期统计结果

### 实验1
- 活检率降低: 35-45% (95% CI: 30-50%)
- 灵敏度非劣效: P < 0.05
- PPV提升: +10-15% (95% CI: 5-20%)

### 实验2
- OCT灵敏度: 85-90% (95% CI: 80-95%)
- AUC提升: +0.10 (95% CI: 0.05-0.15), P < 0.001

### 实验3
- 多模态AI AUC: 0.85-0.90
- vs HPV+TCT: AUC差异 +0.05-0.10, P < 0.001
- NRI: >0.20, P < 0.05

### 实验4
- 成本降低: 20-30% (95% CI: 15-35%)
- 筛查步骤减少: 25-35%
- ICER: <5000元/例（成本效益）
