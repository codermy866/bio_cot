# 实时监控使用说明

## 📊 实时监控脚本

已创建实时监控脚本 `realtime_monitor.py`，可以实时查看实验执行进度。

---

## 🚀 使用方法

### 方法1：交互式实时监控（推荐）

在终端中运行，会实时刷新显示实验状态：

```bash
cd /data2/hmy/VLM_Caus_Rm_Mics/experiments/exp_bio3.2/ablation_studies
python realtime_monitor.py
```

**特点**：
- 每30秒自动刷新
- 显示当前正在运行的实验
- 显示所有实验的进度条
- 显示关键指标（AUC、Loss等）
- 按 `Ctrl+C` 退出

**自定义刷新间隔**：
```bash
python realtime_monitor.py --interval 10  # 每10秒刷新一次
```

---

### 方法2：单次查看

只显示一次当前状态，不循环刷新：

```bash
python realtime_monitor.py --once
```

---

### 方法3：后台运行（输出到日志文件）

启动后台监控，日志保存到文件：

```bash
bash start_realtime_monitor.sh
```

查看监控日志：
```bash
tail -f monitor_logs/realtime_monitor_*.log
```

---

## 📊 监控内容

实时监控会显示：

1. **总体进度**
   - 已完成实验数
   - 正在运行实验数
   - 待执行实验数

2. **当前正在运行的实验**
   - 实验名称
   - 当前Epoch进度（进度条）
   - 进程ID、CPU使用率、内存使用率
   - Best AUC
   - 当前Loss

3. **所有实验状态**
   - 实验名称
   - 状态（已完成/进行中/未开始）
   - 进度条和Epoch数
   - Best AUC
   - 当前Loss

---

## 📁 监控日志位置

### 交互式监控
- 直接在终端显示，不保存日志

### 后台监控日志
- **位置**：`ablation_studies/monitor_logs/`
- **文件命名**：`realtime_monitor_YYYYMMDD_HHMMSS.log`

---

## 💡 使用建议

1. **开发/调试时**：使用交互式监控（方法1），可以实时看到进度
2. **长时间运行**：使用后台监控（方法3），日志保存到文件
3. **快速查看**：使用单次查看（方法2），快速了解当前状态

## 🛠️ 故障排除

### 监控脚本无法运行
```bash
# 检查Python环境
python --version

# 检查脚本权限
chmod +x realtime_monitor.py
```

### 无法显示进度
- 确保实验日志文件存在：`各实验/logs/nohup_*.log`
- 确保训练历史文件存在：`各实验/logs/training_history_*.json`

### 刷新太慢/太快
- 使用 `--interval` 参数调整刷新间隔
- 默认30秒，可以设置为10秒（更快）或60秒（更慢）
